什么是 Symbol？

在 ES6 之前，JavaScript 只有 五种基础（原始）数据类型：Undefined、Null、Boolean、Number、String。

Symbol（符号）是 ES6（ECMAScript 2015）引入的第六种基础数据类型：它表示一个独一无二的值，主要用作对象属性名，从根本上避免属性名冲突，常用于模拟“私有”属性，以及定义语言内部协议（如 Symbol.iterator）。

Undefined
typeof → "undefined"
Null
typeof → "object"
Boolean
typeof → "boolean"
Number
typeof → "number"
String
typeof → "string"
Symbol
typeof → "symbol"
ES6 新增 · 第六种

一、创建 Symbol 与类型检测

const hjy_s1 = Symbol();              // 不带描述
const hjy_s2 = Symbol('胡家瑜');       // 带描述，仅用于打印提示
console.log(hjy_s1);                   // Symbol()
console.log(hjy_s2);                   // Symbol(胡家瑜)
console.log(typeof hjy_s1);            // "symbol" —— 全新的类型，不是 string/object
console.log(hjy_s2.description);       // "胡家瑜"（ES2019 的描述属性）

二、独一无二：Symbol 的唯一性

const hjy_a = Symbol('id');
const hjy_b = Symbol('id');
console.log(hjy_a === hjy_b);          // false —— 描述相同，值依然不同
console.log(Symbol() === Symbol());    // false —— 每个 Symbol 都独一无二

三、全局注册表：Symbol.for() 与 Symbol.keyFor()

const hjy_c = Symbol.for('school');    // 在全局注册表登记，没有则创建
const hjy_d = Symbol.for('school');    // 再次查询，拿到同一个值
console.log(hjy_c === hjy_d);          // true —— 共享的 Symbol
const hjy_e = Symbol('未登记');        // Symbol() 创建的不进注册表
console.log(Symbol.keyFor(hjy_c));     // "school"（反查注册键）
console.log(Symbol.keyFor(hjy_e));     // undefined

四、作为对象属性名：模拟“私有”属性

const hjy_score = Symbol('成绩');
const hjy_student = {
    hjy_name: '胡家瑜',                // 普通字符串属性
    [hjy_score]: 98                    // Symbol 属性：用计算属性名写入
};
console.log(hjy_student[hjy_score]);                    // 98
console.log(Object.keys(hjy_student));                  // 看不到 Symbol 属性
console.log(Object.getOwnPropertySymbols(hjy_student)); // 专门获取 Symbol 属性

五、内置 Symbol：Symbol.iterator 迭代器

const hjy_class = {
    hjy_members: ['胡家瑜', '小明', '小红'],
    [Symbol.iterator]() {               // 实现可迭代协议
        const hjy_members = this.hjy_members;
        let hjy_index = 0;
        return {
            next() {
                return hjy_index < hjy_members.length
                    ? { value: hjy_members[hjy_index++], done: false }
                    : { value: undefined, done: true };
            }
        };
    }
};
for (const hjy_stu of hjy_class) { console.log(hjy_stu); }  // 可被 for...of 遍历
console.log([...hjy_class]);                                 // 可展开成数组

六、注意事项：Symbol 的限制

const hjy_sym = Symbol('x');
hjy_sym + 'abc';                       // ① 报错：不能与其他类型隐式运算
Number(hjy_sym);                       // ② 报错：不能转成数字
JSON.stringify({ [hjy_sym]: 1, hjy_ok: 2 });  // ③ Symbol 属性被忽略
String(hjy_sym);                       // ④ 正确做法：显式转换 "Symbol(x)"
hjy_sym.description;                   // ⑤ 或者直接取描述 "x"
