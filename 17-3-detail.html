📚 详情页的 fetch 是怎么写的

详情页的关键是从地址栏拿到 id，再把它拼进接口路径： 17-3-detail.html?id=5 → /products/5。 如果 id 不存在，接口会返回 404，代码用 res.ok 判断后展示"商品不存在"。 

// 1. 从 URL 查询字符串里取出 id（没有就默认 1）
var id = new URLSearchParams(location.search).get('id') || 1;

// 2. 用模板字符串拼接接口地址
var res = await fetch('https://dummyjson.com/products/' + id);

// 3. 404 不会让 fetch reject，要自己判断
if (!res.ok) throw new Error('HTTP ' + res.status);

// 4. 解析成对象，再把字段填到页面上
var product = await res.json();
document.getElementById('title').textContent = product.title;
