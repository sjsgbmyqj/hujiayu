实现要点

🔤
文字取样
离屏 canvas 绘制文字，逐像素读取 alpha 通道，得到粒子的目标坐标
🧲
弹簧吸附
每个粒子用 vx += (目标 - 当前位置) × 系数 并叠加阻尼，平滑聚合成字
🖱️
鼠标斥力
监听 pointermove，半径内的粒子沿远离鼠标方向获得推力，移开后自动归位
🌌
拖尾与辉光
每帧半透明填充形成拖尾，配合 lighter 混合模式叠加出霓虹发光效果
function hjy_loop() {
    ctx.fillStyle = 'rgba(8, 10, 26, 0.20)';   // 半透明填充 → 拖尾
    ctx.fillRect(0, 0, w, h);

    ctx.globalCompositeOperation = 'lighter';  // 叠加发光
    hjy_particles.forEach(function (p) {
        p.vx += (p.tx - p.x) * 0.022;          // 弹簧吸附
        p.vy += (p.ty - p.y) * 0.022;
        p.vx *= 0.90; p.vy *= 0.90;            // 阻尼
        p.x += p.vx; p.y += p.vy;
    });
    requestAnimationFrame(hjy_loop);
}
