实现要点

  • 底部导航使用 flex 布局，四个导航项 flex: 1 自适应均分，宽度 100% 全屏；
  • position: sticky; bottom: 0 让导航始终贴在屏幕底部（手机端全屏时与 fixed 效果一致）；
  • 图标通过 <use href="#icon-xxx"> 引用页面顶部的 SVG 精灵，一次定义处处复用；
  • SVG 支持多色图标（见首页「蛋糕烘焙」），单色图标用 CSS color 控制颜色。

SVG 图标用法

<svg class="hjy_svg" aria-hidden="true">
  <use href="#icon-shouye"></use>
</svg>

本页 SVG 精灵来自 font/ 目录 iconfont 项目的导出，通过 symbol + use 实现矢量缩放与复用。
