➕ 一、增删元素（会改变原数组）

1

push() / pop() —— 栈：后进先出

push 在尾部追加，返回新长度；pop 删除最后一个，返回被删元素

等待操作…
var hjy_len = hjy_fruit.push('🍓草莓');
// 返回新长度，原数组被改变

var hjy_last = hjy_fruit.pop();
// 返回并删除最后一个元素
2

unshift() / shift() —— 队列

unshift 在头部插入，shift 删除第一个；其余元素下标整体移动

等待操作…
hjy_fruit.unshift('🍒樱桃'); // 头部插入
hjy_fruit.shift();           // 头部删除

// 下标会整体后移 / 前移，效率低于 push / pop
3

splice() —— 万能手术刀

一个方法完成删除 / 插入 / 替换，返回被删掉的元素，原数组被改变

等待操作…
hjy_fruit.splice(1, 2);            // 纯删除
hjy_fruit.splice(1, 0, '🍓','🍒'); // 纯插入
hjy_fruit.splice(1, 2, '🥝猕猴桃'); // 替换
4

reverse() —— 反转顺序

把元素首尾颠倒，直接改变原数组，返回值就是原数组本身

等待操作…
var hjy_back = hjy_fruit.reverse();
// hjy_back === hjy_fruit → true（同一个数组）

🔍 二、查找与判断（成绩单：[88, 95, 62, 71, 100, 53]）

5

sort() —— 排序

传入比较函数决定顺序；不传则按字符串 Unicode 排序（数字会出错）

等待操作…
hjy_scores.sort(function (a, b) {
    return a - b;   // 升序；b - a 为降序
});
6

indexOf() / lastIndexOf()

按值查找下标，找不到返回 -1；lastIndexOf 从尾部开始找

等待操作…
hjy_fruit.indexOf('🍇葡萄');     // 0 起，找不到 -1
hjy_fruit.lastIndexOf('🍇葡萄'); // 从后往前找
7

includes() —— 是否包含

返回 true / false，比 indexOf() !== -1 更语义化

等待操作…
hjy_fruit.includes('🥭');
// true → 水果篮里有它；false → 没有
8

find() / findIndex()

按条件（回调函数）查找：find 返回元素，findIndex 返回下标

等待操作…
hjy_scores.find(function (s) {
    return s < 60;      // 返回第一个满足条件的元素
});
hjy_scores.findIndex(function (s) { return s < 60; });
9

some() / every() —— 逻辑判断

some：有一个满足即为 true；every：全部满足才为 true

等待操作…
hjy_scores.some(function (s) { return s < 60; });
hjy_scores.every(function (s) { return s >= 60; });
// 空数组：some → false，every → true
10

filter() —— 过滤

留下满足条件的元素，返回新数组，原数组不变

等待操作…
var hjy_pass = hjy_scores.filter(function (s) {
    return s >= 60;
});

🔁 三、遍历与变换

11

forEach() —— 逐个遍历

对每个元素执行一次回调，没有返回值（undefined），适合做"依次点亮"

等待操作…
hjy_fruit.forEach(function (item, index) {
    console.log(index, item);
});
// 回调参数：(元素, 下标, 数组本身)
12

map() —— 映射加工

每个元素经过函数加工，返回等长的新数组；原数组不变

等待操作…
var hjy_new = hjy_fruit.map(function (item, i) {
    return (i + 1) + '.' + item;
});
13

reduce() —— 归并累加

把数组"压"成一个值：求和、求平均、求最大值都靠它

等待操作…
var hjy_total = hjy_scores.reduce(function (sum, cur) {
    return sum + cur;
}, 0);   // 第二个参数是初始值
14

flat() —— 拍平多维数组

把嵌套数组"压扁"，参数代表拍平几层，默认 1 层

等待操作…
var hjy_nest = ['🍎', ['🍌', '🍇'], ['🍊', ['🍉']]];
hjy_nest.flat();    // ['🍎','🍌','🍇','🍊',['🍉']]
hjy_nest.flat(2);   // ['🍎','🍌','🍇','🍊','🍉']

🧩 四、拼接、截取与转换

15

concat() —— 合并数组

把两个（或多个）数组拼成一个新数组，原数组都不变

等待操作…
var hjy_all = hjy_fruit.concat(['🍓草莓', '🍒樱桃']);
// 也可以写：hjy_fruit.concat(arr2, arr3)
16

slice() —— 截取片段

含头不含尾 [start, end)，支持负下标；返回新数组，原数组不变

等待操作…
hjy_fruit.slice(1, 3);  // 取下标 1、2
hjy_fruit.slice(-2);    // 取最后两个
hjy_fruit.slice();      // 复制整个数组
17

join() —— 拼成字符串

用分隔符把元素连起来；默认是逗号，常用于生成路径、标签

等待操作…
hjy_fruit.join(' - '); // 指定分隔符
hjy_fruit.join('');    // 无缝拼接
hjy_fruit.join();      // 默认逗号 ,
+

链式调用 —— 方法串成一条链

filter / map / sort 都返回数组，所以可以一直"点"下去

等待操作…
hjy_scores
  .filter(function (s) { return s >= 60; })
  .sort(function (a, b) { return b - a; })
  .map(function (s) { return s + '分'; });

⚖️ 小结：会不会改变原数组？

❌ 会改变原数组（有"副作用"）

push、pop、shift、unshift、splice、sort、reverse、fill、copyWithin

记忆口诀："进出的、动刀的、排序的"都会直接在原数组上动手脚，调用后原数组就变了。

✅ 不改变原数组（返回新结果）

concat、slice、map、filter、flat、join、indexOf、includes、find、findIndex、some、every、reduce、forEach

记忆口诀："查一查、算一算、复制一份"的都不动原数组，需要用一个新变量接收返回值。
