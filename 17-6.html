💻 两种写法对照

Promise 链式写法（17-6 前半段）
function hjy_cook() {
    hjy_buy()                                  // 买原料 6s
        .then(function () {
            return hjy_take();                 // 取原料 2s
        })
        .then(function () {
            // 和面、和馅同时开始
            return Promise.all([hjy_dough(), hjy_filling()]);
        })
        .then(function () {
            return hjy_wrap();                 // 包饺子 5s
        })
        .then(function () {
            return hjy_eat();                  // 吃饺子 2s
        })
        .catch(function (err) {                // 任何一步失败都到这里
            console.log('流程中断：', err.message);
        });
}
async / await 写法（更接近同步代码）
async function hjy_cook() {
    try {
        await hjy_buy();                       // 等买完
        await hjy_take();                      // 等取回

        // 两个都启动，再一起等：并行
        await Promise.all([hjy_dough(), hjy_filling()]);

        await hjy_wrap();                      // 等包完
        await hjy_eat();                       // 开吃
        console.log('完成，总耗时约 19 秒');
    } catch (err) {
        console.log('流程中断：', err.message);
    }
}

⚠️ 并行还是串行，只看你什么时候 await： await A(); await B(); 是一个接一个（串行，7 秒）； await Promise.all([A(), B()]) 才是同时开始（并行，4 秒）。

📚 三个必须记住的点

pending进行中（等待中）
fulfilled成功，走 resolve / then
rejected失败，走 reject / catch

1. Promise 包装定时器：本页的每一步都是 new Promise(function (ok, no) { setTimeout(ok, ms); }) —— 把"回调式"的 setTimeout 变成可以 await 的 Promise。
2. Promise.all 是"全部成功才算成功"：和面、和馅任意一个失败，整个 Promise.all 立刻 reject（fail-fast），后面的包饺子不会执行。
3. 状态一旦改变就不能再改：一个 Promise 从 pending 变成 fulfilled 或 rejected 之后，永远保持这个结果，所以同一份数据可以多次 await。
