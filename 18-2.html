分层设计思想
自上而下分为接入层、网关层、业务层、中间件层与数据层，每层只依赖下一层，便于横向扩展与故障隔离。
服务拆分原则
按业务域拆分为用户、商品、订单、支付、库存等微服务，服务间通过消息队列异步解耦，避免强依赖拖垮整条链路。
关于绘制方式
ECharts 是常用的可视化图表库（echarts.apache.org），本页按课程要求不引入第三方库与 CDN，全部图形由 Canvas 2D API 手工绘制。
