📚 三种基本程序结构

➡️
顺序结构
程序默认从上到下依次执行每一条语句
🔀
条件结构（分支）
if / switch / 三元运算符，根据条件选择不同的执行路径
🔁
循环结构
for / while / do-while，重复执行某段代码直到条件不再满足

🔀 条件结构

1

if…else if 多分支判断

输入 0~100 的成绩，程序从高到低逐级判断，输出对应等级

等待输入…
if (hjy_score >= 90) {
    hjy_grade = 'A（优秀）';
} else if (hjy_score >= 80) {
    hjy_grade = 'B（良好）';
} else if (hjy_score >= 70) {
    hjy_grade = 'C（中等）';
} else if (hjy_score >= 60) {
    hjy_grade = 'D（及格）';
} else {
    hjy_grade = 'E（不及格）';
}
2

switch 多路匹配

选择星期几查看当天安排；case 6、7 演示穿透共用同一分支

等待选择…
switch (hjy_day) {
    case 1: hjy_plan = '制定计划'; break;
    case 2: hjy_plan = '网页设计课'; break;
    case 6:
    case 7: hjy_plan = '周末休息'; break;
    default: hjy_plan = '无效日期';
}
3

三元运算符（条件表达式）

语法：条件 ? 值1 : 值2 —— 适合简单的"二选一"判断

等待输入…
var hjy_parity = hjy_num % 2 === 0
    ? '偶数'
    : '奇数';

🔁 循环结构

4

for 循环 · 累加求和

输入 n（1~200），用 for 循环计算 1 + 2 + … + n

等待输入…
var hjy_sum = 0;
for (var hjy_i = 1; hjy_i <= hjy_n; hjy_i++) {
    hjy_sum += hjy_i;
}
5

while 循环 · 倒计时

输入秒数（3~10），程序用 while 生成倒计时序列并动画演示

—
var hjy_n = hjy_secs;
while (hjy_n >= 1) {
    console.log(hjy_n);
    hjy_n--;
}
console.log('发射！');
6

嵌套 for 循环 · 九九乘法表

外层循环控制行、内层循环控制列，对角线（两数相同）高亮显示

点击上方按钮，用嵌套 for 循环生成九九乘法表

for (var hjy_i = 1; hjy_i <= 9; hjy_i++) {
    for (var hjy_j = 1; hjy_j <= hjy_i; hjy_j++) {
        // 生成 hjy_i × hjy_j 单元格
    }
}
7

break 与 continue

遍历 1~20：continue 跳过 3 的倍数，break 遇到 16 立即终止循环

正常输出 跳过（continue） 终止（break） 未执行 
for (var hjy_i = 1; hjy_i <= 20; hjy_i++) {
    if (hjy_i % 3 === 0) continue; // 跳过 3 的倍数
    if (hjy_i === 16) break;       // 遇 16 终止
    // 输出 hjy_i
}
