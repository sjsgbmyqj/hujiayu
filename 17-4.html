📚 这一页用到的 fetch 核心知识点

所有方法都靠 fetch(url, options) 的第二个参数：method 决定请求方式， headers 决定请求头，body 决定请求体（只能是字符串）。 注意 body 不能用在 GET / HEAD 上；POST 提交 JSON 时必须声明 Content-Type: application/json。 

// POST 提交 JSON 数据
var res = await fetch('https://jsonplaceholder.typicode.com/posts', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title: '标题', body: '内容', userId: 1 })
});

// 判断 HTTP 状态：404 / 500 不会让 fetch 报错，必须自己判断
if (!res.ok) {
    console.log('接口返回错误状态：', res.status, res.statusText);
}

var data = await res.json();   // 服务器返回的内容
console.log(data);             // POST 成功时返回 201 + 带 id 的新对象

错误分三层：① URL 写错 / 断网 / CORS 被拦 → fetch 直接 reject，进 catch； ② 接口返回 4xx / 5xx → 请求成功但 res.ok === false； ③ 返回的不是 JSON → res.json() 抛解析错误。三者都要分别处理。
