🗂 一眼看懂：对象 vs 字符串

对象 Object
"键值对"集合，用 { } 装起来，靠 属性名 取值
字符串 String
一串字符，靠 下标 取值，不可变，方法都返回新串
共同点
都能用 length / 下标访问 / for…of，都能被解构

🧱 一、对象 Object —— 键值对的集合

1

创建对象：字面量 vs 构造函数

最常用的是 { } 字面量；new Object() 写法啰嗦，不推荐

等待操作…
var hjy_stu = {
    name: '胡家瑜',
    age: 20,
    major: '高级网页设计'
};
2

访问属性：点语法 vs 中括号

obj.key 简单直观；obj['key'] 支持变量与特殊字符，是动态取值的唯一选择

等待操作…
hjy_stu.name        // '胡家瑜'
hjy_stu['name']     // 等价写法
var k = 'age';
hjy_stu[k]          // 变量名取值，点语法做不到
3

增 / 改 / 删属性

对象天生可变：赋值即增改，delete 负责删除

等待操作…
hjy_stu.hobby = '写代码';  // 没有就新增
hjy_stu.age = 21;          // 已有就修改
delete hjy_stu.score;      // 删除属性
4

遍历对象：for…in / keys / values / entries

for…in 逐个点亮属性行；三个静态方法一次拿到键、值、键值对

等待操作…
for (var k in hjy_stu) {
    console.log(k, hjy_stu[k]);
}
Object.keys(hjy_stu);    // ['name','age',...]
Object.values(hjy_stu);  // ['胡家瑜',20,...]
Object.entries(hjy_stu); // [['name','胡家瑜'],...]
5

对象的方法与 this

属性值是函数时就叫方法；方法里的 this 指向调用它的对象

等待操作…
var hjy_stu = {
    name: '胡家瑜',
    sayHi: function () {
        return '大家好，我是' + this.name;
    }
};
hjy_stu.sayHi(); // this === hjy_stu
6

解构赋值 & 展开运算符

{ } 解构一次取出多个属性；… 展开可以浅拷贝 / 合并对象

等待操作…
var { name, age } = hjy_stu;   // 解构
var { city: hjy_addr = '未知' } = hjy_stu; // 重命名 + 默认值
var hjy_copy = { ...hjy_stu, age: 21 };    // 展开合并
7

Object.assign 合并 & JSON 序列化

assign 把后面的对象合并进第一个；JSON 用于存字符串 / 网络传输

等待操作…
Object.assign(hjy_stu, { grade: '大二', city: '北京' });
var hjy_text = JSON.stringify(hjy_stu); // 对象 → 字符串
var hjy_back = JSON.parse(hjy_text);    // 字符串 → 对象
8

in / hasOwnProperty / 可选链 ?.

in 判断属性是否存在，?. 让深层取值不再报错

等待操作…
'name' in hjy_stu;             // true
hjy_stu.hasOwnProperty('name'); // true（只看自身）
hjy_stu.contact?.phone;        // 有就取，没有给 undefined
hjy_stu.address?.city;         // 不会报错（对比 address.city）

🔡 二、字符串 String —— 一串不可变的字符

9

length、下标与不可变性

字符串像数组一样能用 [i] 读字符，但不能改写——这就是"不可变"

等待操作…
hjy_text.length;   // 字符个数
hjy_text[0];       // 第一个字符
hjy_text[0] = 'X'; // 无效！字符串只读
hjy_text = '新值';  // 只能整体重新赋值
10

查找：indexOf / includes / startsWith / endsWith

找不到返回 -1；头尾判断返回 true / false

等待操作…
hjy_text.indexOf('Script');   // 出现位置，没有 -1
hjy_text.includes('Java');    // true / false
hjy_text.startsWith('Java');  // 是否以…开头
hjy_text.endsWith('有趣');     // 是否以…结尾
11

截取：slice() 与 substring()

都是含头不含尾；区别在负数：slice 支持倒数，substring 把负数当 0

等待操作…
hjy_text.slice(0, 4);    // 'Java'
hjy_text.slice(-3);      // 倒数 3 个字符
hjy_text.substring(0, 4);// 同为 'Java'
hjy_text.substring(-3);  // 负数当 0 → 整串
12

替换：replace() 与 replaceAll()

replace 只换第一个，replaceAll 换全部（也可用正则 /g）

等待操作…
hjy_text.replace('a', '@');      // 只换第一个
hjy_text.replaceAll('a', '@');   // 全部替换
hjy_text.replace(/a/g, '@');     // 正则 + g 等价
13

大小写与整理：toUpperCase / trim / padStart / repeat

全部返回新字符串：转大小写、去空格、补位、重复

等待操作…
hjy_text.toUpperCase();       // 全大写
'  hi  '.trim();              // 去掉两端空格
'7'.padStart(3, '0');         // '007'
'哈'.repeat(3);               // '哈哈哈'
14

split() ↔ join()：字符串与数组互转

split 拆成数组 → 数组方法处理 → join 拼回字符串（反转字符串经典套路）

等待操作…
hjy_text.split('');                  // 逐字符拆成数组
hjy_text.split('').reverse().join(''); // 反转
'2026-10-29'.split('-');             // ['2026','10','29']
15

模板字符串 ` ` 与 ${ }

反引号支持换行与插值；比 + 拼接清爽得多

等待操作…
var hjy_info = `大家好，我是${hjy_stu.name}，
今年 ${hjy_stu.age} 岁，正在学 ${hjy_stu.major}。`;
16

遍历字符串：for…of 与展开

字符串是可迭代对象，能 for…of、能展开成数组

等待操作…
for (var ch of hjy_text) {
    console.log(ch);
}
[...hjy_text]; // 展开成字符数组

⚖️ 小结：对象与字符串的三个关键区别

🧱 对象 Object（引用类型）

① 用属性名取值：obj.name / obj['name']
② 可变：随时增删改属性，原对象直接被改
③ 赋值传的是地址：两个变量指向同一对象，改一个另一个也变
④ 比较的是地址：{} !== {}

🔤 字符串 String（基本类型）

① 用下标取值：str[0] / str.charAt(0)
② 不可变：所有方法都返回新串，原串纹丝不动
③ 赋值传的是值的副本：互不影响
④ 比较的是内容：'ab' === 'ab' → true
