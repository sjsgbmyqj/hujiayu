下导航实现要点

  • 导航容器 display: flex，五个 .hjy_tab 均设置 flex: 1 1 0 与 min-width: 0，宽度自适应等分；
  • width: 100% 铺满屏幕宽度，桌面端放在手机框内，窄屏时 position: fixed 贴底；
  • padding-bottom: env(safe-area-inset-bottom) 适配 iPhone 底部安全区；
  • 选中项用金色描边高亮条 + 图标上移，徽章与红点用 position: absolute 挂在图标右上角；
  • 点击导航切换五个面板，进入「片单」清除数字徽章，进入「我的」清除红点。

字体图标用法（iconfont）

<link rel="stylesheet"
      href="font/font_5244836_gsc19f4yjzd/iconfont.css">

<i class="iconfont icon-shouye"></i>

.hjy_tab_icon {
    font-size: 21px;      /* 改大小 */
    color: #8f8aa5;       /* 改颜色 */
}
.hjy_tab_active .hjy_tab_icon { color: #ffb43a; }

字体图标本质是字体字形，用 font-size 缩放、color 着色，矢量输出不糊边，颜色与尺寸全部由 CSS 控制。
