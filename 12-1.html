基本用法

纯色变量
var(--hjy-primary) 引用颜色
var(--hjy-primary)
渐变变量
多个变量组合成渐变
linear-gradient(var(--hjy-primary), var(--hjy-accent))
计算变量
calc() 与变量混合运算
calc(80% + 20px)
阴影变量
color-mix() 动态透明度
box-shadow with var
间距变量
var(--hjy-spacing) 控制间距
padding: calc(var(--hjy-spacing) / 2)
过渡变量
var(--hjy-transition) 统一动画时长
悬停缩放 var(--hjy-transition)

作用域与覆盖

全局变量
使用 :root 中定义的值
全局 --hjy-primary
局部覆盖
在元素内重新定义变量值
局部覆盖 --hjy-primary
嵌套继承覆盖值
/* :root 中定义 */ :root { --hjy-primary: #667eea; } /* 局部覆盖 */ .hjy-scope-override { --hjy-primary: #e74c3c; background: var(--hjy-primary); }
