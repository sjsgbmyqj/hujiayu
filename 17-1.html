JSON 数据展示台

先看懂 JSON 的语法，再把接口返回的 JSON 拆成能一层层展开的结构树

👤 学生：胡家瑜 · 2026-11-02

① JSON 是什么 JavaScript Object Notation · 数据交换格式

{
  "name": "胡家瑜",
  "age": 20,
  "isStudent": true,
  "skills": ["HTML", "CSS", "JS"],
  "address": {
    "city": "武汉",
    "zip": null
  }
}

JSON 是一段纯文本，只是长得像 JS 对象。它不负责逻辑，只负责“把数据装起来”在不同程序之间传递， 所以接口返回的内容基本都是 JSON。

  • 1键名必须用双引号，单引号或不加引号都不合法："name" ✔ ／ name ✘
  • 2值只能有 6 种类型：字符串、数字、布尔、null、对象、数组
  • 3不能写注释（// 和 /* */ 都不允许）
  • 4最后一个成员后面不能多写逗号：{"a":1,} ✘
  • 5对象用 {}，数组用 []，成员之间用逗号，结尾不加分号
  • 6顶层可以是一个对象、数组，甚至一个数字，但不能几个 JSON 并排
string 字符串 "胡家瑜" 只能用双引号，换行要写成 \n
number 数字 20 / 3.14 / -5 没有 int、float 之分，不能带引号
boolean 布尔 true / false 只能小写，不能是 True、TRUE
null 空值 null 表示“没有值”，不能写 undefined
object 对象 { "k": "v" } 无序的键值对集合，用 {}
array 数组 [1, "a", true] 有序列表，用 []，元素类型可以混用

④ 代码怎么写

取数据 + 解析 fetch → res.json() 内部就是 JSON.parse
async function hjy_load() {
    var res = await fetch(
        'https://jsonplaceholder.typicode.com/users'
    );
    if (!res.ok) throw new Error('HTTP ' + res.status);

    var data = await res.json();   // 文本 → JS 对象

    // 顶层是数组，取第一项里的嵌套值
    console.log(data[0].name);
    console.log(data[0].address.city);
    console.log(data[0].company.name);

    // 想看规范文本，再转回字符串
    var text = JSON.stringify(data, null, 2);
    console.log(text);
}
递归渲染结构树 Object.keys + 递归
function hjy_tree(value, key, depth) {
    var isObj = value !== null
        && typeof value === 'object';

    if (isObj) {
        var keys = Array.isArray(value)
            ? value.map(function (v, i) { return i; })
            : Object.keys(value);

        // 对象 / 数组：递归展开子节点
        return keys.map(function (k) {
            return hjy_tree(value[k], k, depth + 1);
        });
    }

    // 基本类型：直接显示
    return key + ' : ' + JSON.stringify(value);
}

记住三件事：① 接口给的永远是字符串，要 res.json() 或 JSON.parse() 之后才能点出属性 （data.name）；② 想存起来或发给后端，用 JSON.stringify() 转回字符串，它看不见函数、undefined 和注释； ③ 结构树、console.log 的层级，其实就是在递归 Object.keys()——数组看下标，对象看键名。
