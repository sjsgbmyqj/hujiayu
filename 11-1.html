📌 绝对单位

px绝对
像素，最常用的绝对单位。1px 对应屏幕上的一个物理像素点（CSS 逻辑像素），大小固定不随环境变化。
60px
120px
200px

📐 相对单位（字体相关）

em相对
相对于父元素的字体大小。父元素 font-size: 20px 时，1.5em = 30px。会逐层叠加，常用于组件内部缩放。
父级 20px
子级 1.5em = 30px
rem相对
相对于根元素（html）的字体大小，默认 1rem = 16px。不受父级影响，适合做全局一致的间距与字号体系。
1.25rem = 20px
2rem = 32px

📊 相对单位（尺寸相关）

%相对
相对于父元素对应属性的百分比。父元素宽 100% 时，子元素 width: 50% 即占一半，常用于流式布局。
width: 50%
vw / vh相对
相对于视口宽/高的百分比。1vw = 视口宽度的 1%，1vh = 视口高度的 1%，常用于全屏布局与响应式排版。
10vw
10vh
vmin / vmax相对
取视口宽、高中较小/较大者的百分比。横竖屏切换时表现稳定，适合做自适应的封面图或容器。
20vmin
20vmax
ch / ex相对
ch 相对于字符 "0" 的宽度，常用于控制文本每行字数；ex 相对于字母 x 的高度，实际项目中使用较少。
20ch 字符宽
10ex
